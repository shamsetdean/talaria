03

Données personnelles — RGPD

Ce qui reste sur votre appareil, jamais transmis à un serveur :

✓ Adresses enregistrées (domicile, travail, favoris)

✓ Contacts SMS rapides

✓ Trajets favoris

Géolocalisation : avec votre autorisation (demandée par le navigateur), Talaria utilise votre position pour centrer la carte et calculer des itinéraires. Lors d'une recherche d'itinéraire, votre position ou les points de trajet saisis sont transmis aux API tierces suivantes :

ServiceUsage
IDFM PRIMHoraires et itinéraires transports en commun
SNCFInformations trafic ferroviaire
OpenStreetMap (Overpass)Données cartographiques
API Adresse (data.gouv.fr)Recherche et validation d'adresses
Vélib' (GBFS)Disponibilité des stations
Open-MeteoConditions météo

Talaria ne conserve pas ces données au-delà du temps nécessaire à la requête. Chacun de ces services tiers traite les données selon sa propre politique de confidentialité.

Base légale : consentement, via l'autorisation de géolocalisation accordée dans votre navigateur — révocable à tout moment dans les réglages de votre appareil.

Conformément au RGPD, pour toute question sur ces traitements : shamsetdean@gmail.com.

04

Sécurité

Les clés d'accès aux API tierces nécessitant une authentification (SNCF, IDFM PRIM) sont conservées côté serveur (variables d'environnement Vercel) et ne transitent jamais dans le code envoyé à votre navigateur.
